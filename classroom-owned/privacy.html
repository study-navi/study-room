データの取り扱い

Study Roomは、自習室の入退室と学習記録を教室ごとに管理するサービスです。

保存する情報と利用目的

生徒の氏名・学年・自習日時・学習時間・科目・目標・振り返りを、所属教室の先生が所有するGoogleスプレッドシートに保存します。利用状況の確認、本人の学習履歴、先生の指導・集計・CSV出力に使用します。

生徒の端末には、所属教室、プロフィール、本人の履歴を識別するランダムな生徒IDと端末キー、送信前の記録を保存します。端末を操作できる人はその生徒の履歴を表示できます。共用端末では利用者切替を使用してください。

Googleアカウントとの接続

先生のGoogleアカウントの識別ID、メールアドレス、ログイン状態、教室と保存先の対応をサービス側に保存します。Googleから取得した継続接続用の認証情報は暗号化して保存します。生徒に認証情報を渡しません。

要求するDrive権限は、このアプリで作成・利用するファイルに限定したdrive.fileです。先生の不在時にも生徒の記録を送受信するために継続接続を使用します。ファイルの一般公開や他教室への共有は行いません。Google APIから受け取った情報は上記機能に使用し、広告目的での利用・販売は行いません。取り扱いはGoogle API Services User Data PolicyのLimited Use要件に従います。

サービス側の保存とバックアップ

サーバーはGoogleと通信するために学習記録を処理します。通信が途切れた際の欠落・二重送信を防ぐため、送信途中の記録をサービス側の非公開領域に一時保存します。保存完了を確認すると、この一時データを削除します。先生のDriveには日次および手動の非公開バックアップを作成します。

Cloudflare版では、教室の対応情報、ログイン状態、暗号化した認証情報、送信途中の記録をCloudflareの非公開ストレージで処理します。保存場所が日本国内に限定される構成ではありません。

権限の取り消し・記録の訂正

Googleアカウントの接続設定から許可を取り消せます。取り消すと送受信が停止します。スプレッドシートとバックアップは先生のDriveに残ります。記録の訂正・端末の引継ぎは所属教室の先生へ、サービス側の登録情報の削除は運営窓口（{{CONTACT}}）へお問い合わせください。
